🍴 Food Munch Web Page

A responsive restaurant website built using HTML and CSS. The project showcases a food ordering/restaurant landing page with a modern layout, menu section, delivery and payment information, social media section, and footer.

🚀 Features
Responsive restaurant landing page
Navigation menu
Hero/banner section
Why Choose Us section
Explore Menu section
Healthy food section
Delivery and Payment section
Payment method icons
Social media section
Responsive design for different screen sizes
Custom Google Fonts
Food images from CCBP resources
🛠️ Technologies Used
HTML5
CSS3
Flexbox
CSS Media Queries
Google Fonts
